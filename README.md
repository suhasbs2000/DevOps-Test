# Harbor House Hotel

A responsive hotel website built using Next.js, React, and TypeScript.

## Run Locally

Install dependencies:

```bash id="4pd2u8"
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Production Build

```bash id="v1c7rz"
npm run build
npm start
```

## DevOps Learning Project

This repository is used to learn and practise:

- Git and GitHub
- Docker images and containers
- GitHub Actions and CI/CD
- Google Cloud virtual machines
- Automated application deployment

## Deployment Goal

Containerize the application using Docker and deploy it to a Google Cloud virtual machine. Later, configure CI/CD so changes pushed to GitHub automatically trigger a new deployment.

## Notes

The hotel website currently uses sample content and is a frontend demo. The availability form does not connect to a real booking system.
